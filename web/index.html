Knobby SWU Base Counter

Base damage tracker for Star Wars: Unlimited on the Knobby rotary display.

Install

  1. Open this page in Chrome, Edge or Opera on a computer. Other browsers can't talk to USB devices.
  2. Connect the Knobby with a USB-C data cable.
  3. Click Install, pick the device's serial port, and confirm.
Your browser can't install firmware. Use Chrome, Edge or Opera on a computer. This page must be opened over HTTPS to install firmware.
If you see "Your ESP32 board is not supported", flip the USB-C plug 180 degrees, refresh the page and try again. The plug orientation decides which chip the cable reaches.
Coming from the Magic version? The installer offers to erase the device. Either choice works, since this firmware keeps its settings separately.

Using it

  • Turn the knob clockwise to deal damage to a base, counter-clockwise to heal. The number counts up from 0 toward the base's HP.
  • With two or more players, tap a player's half first, then turn the knob.
  • Hold a player's area to open their menu: base HP, initiative, Force token, name and color.
  • Swipe in from any edge for the main menu: Game Mode (players, base HP), Tools (coin flip, round timer, event log, pick first player) and Settings.
